# Модуль фитнес-трекера

Учебный проект по дисциплине «Основы разработки на языке Go»: структуры,
эмбеддинг, методы и интерфейсы. Решение на основе
[шаблона Яндекс Практикума](https://github.com/Yandex-Practicum/go1fl-sprint5-final).

## Запуск

Требуется Go 1.24.1 или новее. Из корня репозитория:

```sh
go run ./cmd/tracker
```

Программа выводит персональные данные, отчёты о прогулках и тренировках.
Ошибочные записи из демонстрационного набора логируются, обработка следующих
записей продолжается. `cmd/tracker/main.go` сохранён без изменений.

## Структура решения

| Пакет | Назначение |
| --- | --- |
| `internal/spentenergy` | Расчёт дистанции, средней скорости и калорий |
| `internal/personaldata` | Структура `Personal` и метод `Print` |
| `internal/trainings` | Структура `Training`, разбор и отчёт о тренировке |
| `internal/daysteps` | Структура `DaySteps`, разбор и отчёт о прогулке |
| `internal/actioninfo` | Интерфейс `DataParser` и обработка набора записей |

В `Training` и `DaySteps` встроена `personaldata.Personal`, поэтому доступны
поля пользователя и метод `Print`. Интерфейс `DataParser` реализуют указатели
`*Training` и `*DaySteps`: метод `Parse` меняет состояние структуры.

## Входные данные и расчёты

- Тренировка: `3456,Ходьба,3h00m` или `678,Бег,5m`.
- Прогулка: `678,0h50m`.
- Вес задаётся в килограммах, рост — в метрах.
- Длительность разбирается через `time.ParseDuration`, включая `1.5h` и `30.5m`.
- При разборе шаги и длительность должны быть больше нуля. Пробелы в числовых
  полях не удаляются автоматически. Ошибка не изменяет прежнее состояние.
- Вид тренировки проверяется в `ActionInfo`; неизвестный вид возвращает ошибку
  `неизвестный тип тренировки`.
- Расчёт калорий отклоняет неположительные шаги, вес, рост и длительность,
  а также `NaN` и бесконечные значения веса и роста.

Формулы из задания:

```text
длина шага (м) = рост × 0.45
дистанция (км) = шаги × длина шага / 1000
скорость (км/ч) = дистанция / длительность в часах
калории при беге = вес × скорость × длительность в минутах / 60
калории при ходьбе = калории при беге × 0.5
```

`Distance` возвращает 0 при неположительном количестве шагов или некорректном
росте. `MeanSpeed` возвращает 0 при неположительной длительности.
Числа округляются до двух знаков только при формировании отчёта.

## Тестирование проекта

Рядом с файлами, которые вы будете редактировать, находятся файлы с суффиксом _test.go. В них содержатся юнит-тесты, проверяющие корректность вашей реализации. Эти тесты автоматически запускаются на GitHub. Чтобы работа была зачтена, ваш код должен успешно проходить все тесты. Обратите внимание: изменять содержимое тестов запрещено.

Вы можете запускать тесты локально, выполнив следующие команды в корневой директории репозитория:

```bash
go mod tidy
go test -v ./...
```

Дополнительная проверка:

```sh
go vet ./...
go test -cover ./...
```

Исходные тесты сохранены без изменений. Добавлены отдельные тесты граничных
значений, сохранения состояния при ошибке разбора, соответствия интерфейсу
и продолжения обработки после ошибок парсинга и расчёта отчёта.
